# Deep Learning – Laboratory Practice IV (LP4)

This repository contains the implementations of **Deep Learning Laboratory Practice IV (LP4)** assignments.

The practicals cover deep learning frameworks, feedforward neural networks, image classification, autoencoders for anomaly detection, CBOW, and transfer learning using CNN architectures.

## 📚 Assignments

| No. | Assignment | Dataset | File |
|-----|------------|---------|------|
| 1 | Study of Deep Learning Packages | — | `Assignment_1_DL.ipynb` |
| 2 | Feedforward Neural Network using Keras & TensorFlow | MNIST | `Assignment_2_MNIST_DL.ipynb` |
| 2 | Feedforward Neural Network using Keras & TensorFlow | CIFAR-10 | `Assignment_2_CIFAR10_DL.ipynb` |
| 3 | Image Classification Model | MNIST | `Assignment_3_MNIST_DL.ipynb` |
| 4 | Anomaly Detection using Autoencoder | Credit Card | `Assignment_4_CreditCard_DL.ipynb` |
| 4 | Anomaly Detection using Autoencoder | ECG | `Assignment_4_ECG_DL.ipynb` |
| 5 | Continuous Bag of Words (CBOW) | Text Dataset | `Assignment_5_DL.ipynb` |
| 6 | Transfer Learning using CNN | Caltech-101 | `Assignment_6_Caltech101_DL.ipynb` |
| 6 | Transfer Learning using CNN | CIFAR-10 | `Assignment_6_CIFAR10_DL.ipynb` |
